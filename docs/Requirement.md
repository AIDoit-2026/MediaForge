# MediaForge 需求文档

> 状态：MVP 范围已确认  
> 目标平台：Windows 10/11 x64  
> 首版交付形态：免安装的 portable 文件夹

## 1. 产品目标

MediaForge 是一款本地运行的桌面媒体转换工具。用户无需理解 FFmpeg 命令行，即可批量完成常见的视频、音频转码任务，并能查看进度、错误原因和实际执行参数。

首版优先保证：常用转换可靠、批量队列清晰、参数不会产生无效组合、中文和英文均可完整使用、复制应用目录即可迁移配置并运行。

## 2. MVP 范围

### 2.1 平台与发布

- 使用 C#、WinUI 3 和 Windows App SDK 开发。
- 首版仅支持 Windows 10/11 x64。
- 采用 unpackaged、自包含的 portable 文件夹发布；用户直接运行 `MediaForge.exe`。
- 所有用户设置保存在 `MediaForge.exe` 同级的 `config` 文件夹，不写入安装目录之外的应用配置位置。
- 应用目录整体复制到另一台满足系统要求的电脑后，设置可随之迁移。
- `config` 不可写时仍允许应用使用内置默认参数启动，但不持久化设置、队列和日志，并在主界面持续显示醒目警告。
- portable 包必须说明其依赖的 Windows App Runtime 交付方式。

说明：WinUI 3 应用包含运行时和原生文件，用户提供的 FFmpeg 也通常包含多个文件；首版的“portable”定义为免安装文件夹，不承诺只有一个 exe 文件。

### 2.2 语言与外观

- 提供完整的简体中文和英文界面、提示、错误摘要与预设名称。
- 支持运行时切换语言，无需重启应用。
- 面向用户的字符串必须放入资源文件，不得散落在 XAML 或 C# 代码中。
- 支持浅色、深色和跟随系统三种主题；切换后立即生效。
- 核心流程可仅用键盘完成，并兼容高对比度模式和常见文本缩放设置。

### 2.3 输入与媒体信息

- 支持添加单个或多个文件、拖放文件，以及添加文件夹。
- 添加文件夹使用专用导入对话框，可选择目录、是否递归，并按文件名设置关键字、简单通配符或正则表达式过滤。
- 关键字匹配不区分大小写；简单通配符至少支持 `*` 和 `?`；正则表达式必须在扫描前校验，并设置匹配超时。
- 对话框记住上次使用的目录、递归和过滤条件；首版不支持保存多套导入模板。
- 通过 FFprobe 读取媒体信息，包括容器、时长、视频/音频/字幕流、编码、分辨率、帧率、采样率、声道和可获取的码率。
- 无法识别或损坏的文件不得导致应用崩溃；队列项显示可读错误，并可展开查看技术细节。
- 路径包含中文、空格和常见特殊字符时必须正常工作。

### 2.4 转换能力

- 支持视频转视频、视频转音频、音频转音频。
- 格式能力以当前 FFmpeg 构建实际报告的 demuxer、muxer、decoder 和 encoder 为准；界面只展示可用选项。
- 首版重点覆盖以下常用容器和编码：
  - 视频容器：MP4、MKV、MOV、WebM。
  - 视频编码：H.264、H.265/HEVC、AV1、VP9（仅展示当前 FFmpeg 可用的编码器）。
  - 音频容器/格式：MP3、M4A/AAC、FLAC、WAV、Opus。
- AVI、FLV、TS 等格式可由 FFmpeg 能力驱动开放，但不作为首版预设和完整兼容性验收矩阵的一部分。
- 支持选择输出文件夹和“与源文件相同”。
- 支持输出命名模板。首版支持 `{name}`、`{ext}`、`{preset}`、`{index}`、`{date}`、`{width}`、`{height}`、`{resolution}`、`{video_codec}` 和 `{audio_codec}`；非法模板在开始任务前提示。
- 文件冲突策略支持覆盖、跳过和自动重命名。自动重命名必须稳定产生不冲突名称，例如 `name (1).mp4`。

### 2.5 编码参数

- 视频可配置编码器、分辨率、帧率，以及与编码器匹配的质量或码率模式。
- 软件视频编码至少支持 CRF 或等价质量模式、目标码率模式和编码预设（具体选项由编码器能力决定）。
- 音频可配置编码器、采样率、声道数和码率；无损编码器不显示无意义的码率选项。
- 支持可用时的 NVENC、Intel QSV 和 AMD AMF 编码。启动或刷新能力时探测本机可用编码器，探测失败时回退到软件编码。
- D3D12VA 作为硬件解码能力处理，不作为视频编码器列出。
- 支持两遍编码，但只在兼容的软件码率模式中显示；CRF/CQ、流复制和不兼容的硬件编码模式不得启用两遍编码。
- 支持裁剪、缩放、旋转和补边；开始前校验输出尺寸及像素格式限制。
- 支持按一个连续时间范围裁剪媒体。
- 支持从视频提取一个音频流。
- 首版字幕仅支持选择一个外部 SRT 文件烧录到视频；不做软字幕复制、字幕转码、ASS/SSA 和内嵌字幕选择。
- 默认不复制章节、附件、普通字幕流或额外媒体流。尽量保留源文件中的作者、标题、专辑名，以及目标容器兼容时的封面；保留失败不得导致整个转换失败。

### 2.6 队列与执行

- 队列支持添加、移除、重新排序和清空。
- 每个队列项在开始前保存独立的输入、输出、预设和参数快照，之后修改全局编辑区不得悄悄改变已开始任务。
- 可配置并行任务数，默认值为 1，允许范围为 1–4。
- 显示单文件进度、总进度、处理速度、已用时间和预计剩余时间。无法估算时显示“正在计算”，不得显示虚假数值。
- 首版不提供暂停、继续或单任务取消；用户通过“退出应用”提前结束所有运行任务。
- 关闭主窗口时应用缩小到系统托盘并继续转换；托盘菜单提供打开主窗口和退出应用。
- 应用采用单实例运行；再次启动 exe 时激活并显示已有主窗口，避免多个实例同时写入配置和队列。
- 退出应用时终止所有 FFmpeg 子进程并删除临时输出，然后持久化可恢复队列。
- 队列变化后持久化到 `config`。应用重新启动时恢复未完成的任务配置，但不续接旧 FFmpeg 进程，也不自动开始；之前正在运行的任务显示为“已中断”，用户重新开始后从头转换。
- 失败或退出后不得把不完整文件当作成功结果，临时文件一律删除。
- 异常退出遗留的、由任务清单明确记录的临时文件在下次启动时清理；不得按宽泛通配符删除未知文件。

### 2.7 预设

- 内置少量经过验证的预设，至少包括 YouTube 1080p、高质量归档和仅音频。
- 用户可以新建、另存、重命名和删除自定义预设。
- 内置预设不可被永久覆盖；修改后应另存为用户预设。
- 预设只包含输出格式及转换参数，不包含输入文件、输出目录、文件冲突策略或并行任务数。
- 预设采用带版本号的 JSON 格式，为未来迁移保留版本字段。

### 2.8 日志与错误

- 显示每个任务的 FFmpeg 参数和标准输出/错误输出。
- 调用 FFmpeg 时使用结构化参数传递，不通过拼接 shell 命令执行。
- 用户界面先显示可操作的错误摘要，并允许展开原始 FFmpeg 输出。
- 日志写入 `config/logs`，设置最大文件数或总大小，避免无限增长。
- 支持从界面复制诊断信息；诊断信息应包含应用版本、FFmpeg 版本、任务参数和错误输出。

### 2.9 设置与 FFmpeg

- 设置保存在 `config/settings.json`，写入使用临时文件加原子替换，降低异常退出导致配置损坏的风险。
- 设置至少包含语言、主题、FFmpeg 路径、默认输出位置、默认冲突策略、并行任务数、最近使用的转换选项和最近一次文件夹导入条件。
- 用户自行下载 FFmpeg。应用按以下优先级寻找 FFmpeg/FFprobe：用户指定目录、`MediaForge.exe` 所在目录。
- FFmpeg 与 FFprobe 必须来自同一工具目录并通过版本/能力检查。
- 应用不主动检查最新版本，也不下载或更新 FFmpeg。只有当前版本或构建缺少用户所选功能时，才阻止该任务并明确提示用户更新或更换 FFmpeg。
- 应用完全离线工作，不上传媒体、文件名、路径、日志或使用统计。

## 3. 后续版本候选

以下功能有价值，但不纳入首版 MVP：

- 从视频提取缩略图或指定时间帧。
- 从视频片段创建 GIF。
- 音量峰值标准化或 EBU R128 响度标准化。
- 更完整的容器/编码器兼容矩阵和高级 FFmpeg 参数。
- 软字幕、字幕转码、ASS/SSA 与内嵌字幕选择。
- 更完整的封面和元数据映射。

## 4. 明确不做

下列原需求已被删除线排除，不进入设计与任务清单：

~~- Watch-folder mode（监视文件夹模式）~~

~~- Command-line interface companion（命令行配套工具）~~

根据范围确认，首版还明确不做：

- 暂停、继续和单任务取消。
- 使用外部音频替换现有音轨。
- 文件夹导入条件模板（只记住上次输入）。
- FFmpeg 自动检查、下载或更新。

## 5. 非功能要求与验收基线

- 转换、探测、日志读取和文件扫描不得阻塞 UI 线程；转换进行时窗口仍可移动、缩放和操作队列。
- 应用异常、FFmpeg 崩溃、输入损坏或单个任务失败不得导致整个队列丢失控制；其他可执行任务可继续。
- 进程并发和应用退出不得遗留失去管理的 FFmpeg 子进程。
- 对不存在、不可读、不可写、磁盘空间不足和路径冲突给出明确提示。
- 应用启动时间以发布构建在目标最低配置上的实测结果为准；目标值待建立性能基线后填写。
- 日常转换不要求管理员权限。
- 删除应用目录即可完成卸载；若所有状态均保存在目录内，不应留下应用专有用户数据。
- Windows 10 最低支持版本暂定 1809（build 17763）；若实现所需 Windows App SDK 功能要求更高版本，在开发前记录并更新此下限。
- 首版至少验证 Windows 10 与 Windows 11 各一个受支持版本，以及 NVIDIA、Intel、AMD 中实际可获得的硬件组合；未具备的硬件路径必须能隐藏或安全回退。

## 6. 需求变更摘要

- 明确首版是 portable 文件夹，而非强制单 exe。
- 把需求分为 MVP、后续候选和明确不做，避免推荐功能扩大首版范围。
- 将 AVI、FLV、TS 等长尾格式改为能力驱动支持，不承诺首版逐项调优。
- 将 D3D12VA 从编码器选项改为硬件解码能力。
- 为两遍编码、CRF/CQ、硬件编码等互斥参数补充界面约束。
- 增加 FFprobe 媒体探测、参数快照、配置原子写入、日志轮转、离线与隐私、Unicode 路径、临时文件和子进程清理要求。
- 将缩略图、GIF、响度标准化移到后续版本，并将队列恢复纳入 MVP。
- 根据确认结果，改为用户提供 FFmpeg、托盘后台运行、退出时清理、队列恢复和简单 SRT 烧录。
- 增加带递归、关键字、通配符和正则表达式的文件夹导入对话框，并限定为记住上次输入。

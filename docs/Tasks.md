# MediaForge MVP 任务清单

> 状态：MVP 执行基线  
> 依据：[Requirement.md](./Requirement.md) 与 [Design.md](./Design.md)  
> 原需求中带删除线的监视文件夹和 CLI 不在本清单中。

## 0. 冻结范围与验证技术风险

- [x] 记录产品决策并同步需求、设计和任务范围。
- [x] 确认外部 SRT 烧录、Windows 10 1809 暂定下限及用户自备 FFmpeg。
- [ ] 冻结其余 MVP 容器、视频编码器和音频编码器兼容矩阵。
- [ ] 做 unpackaged WinUI 3 portable 发布原型，在干净的 Windows 10/11 环境验证直接运行。
- [ ] 验证系统托盘、单实例和关闭窗口隐藏行为在 unpackaged 模式下可用。
- [ ] 建立短小且可再分发的媒体测试样本及来源说明。

完成条件：portable 与托盘路径有可复现实验结果，支持矩阵可直接用于验收。

## 1. 工程基础

- [x] 使用官方 WinUI 模板创建 `MediaForge.App` unpackaged x64 项目，并建立解决方案。
- [x] 创建 `MediaForge.Core`、`MediaForge.Infrastructure` 和测试项目，落实依赖方向。
- [x] 配置 Debug/Release、版本号、应用图标和发布目录结构。
- [x] 建立依赖注入/组合根、应用级异常处理和结构化日志基础。
- [x] 创建 `config` 路径服务；不可写时进入默认参数临时会话并发布持续警告。
- [x] 建立 CI 或本地一键检查：还原、构建、测试、发布。

完成条件：全新检出可构建、启动，Release portable 产物可从独立目录运行。

## 2. 本地化、主题与主窗口

- [ ] 建立简体中文和英文 `.resw` 资源及缺失资源检查。
- [ ] 实现运行时语言切换并刷新当前窗口内容与文化格式。
- [ ] 实现浅色、深色和跟随系统主题。
- [x] 建立单窗口 `NavigationView`：转换、预设、设置。
- [ ] 实现宽、中、窄三档布局与最小窗口尺寸策略。
- [ ] 为核心控件补齐可访问名称、键盘导航、焦点顺序和高对比度资源。

完成条件：无需重启即可切换语言/主题；键盘可访问三个页面，窄窗口无关键控件被裁切。

## 3. 配置与预设持久化

- [x] 定义带 `schemaVersion` 的设置、预设和可恢复队列 JSON 模型。
- [x] 实现临时文件写入、原子替换、损坏文件备份和默认值恢复。
- [x] 实现设置页：语言、主题、FFmpeg 路径、输出默认值、冲突策略和并行数。
- [x] 保存最近一次文件夹导入的目录、递归、过滤模式和表达式。
- [x] 建立只读内置预设：YouTube 1080p、高质量归档、仅音频。
- [x] 实现用户预设的新建、另存、重命名、删除和版本迁移入口。
- [ ] 实现有界日志保留策略。

完成条件：异常中断写入不会破坏上一份有效配置；复制应用目录后设置和用户预设仍可使用。

## 4. FFmpeg/FFprobe 工具层

- [x] 实现“用户指定目录 → exe 目录”的 FFmpeg/FFprobe 路径解析、同目录检查和版本读取。
- [x] 实现能力探测并缓存 encoders、decoders、muxers、demuxers、filters、hwaccels。
- [x] 实现 NVIDIA NVENC、Intel QSV、AMD AMF 的实际可用性探测。
- [x] 定义结构化工具错误与本地化建议动作。
- [ ] 当所选功能不受当前 FFmpeg 版本或构建支持时，阻止任务并提示更新或更换工具。
- [x] 实现安全进程启动、异步标准输出/错误读取、退出信号和进程树清理。
- [x] 实现 FFmpeg `-progress` 键值流解析。

完成条件：工具缺失或损坏时能诊断；含中文、空格和特殊字符的路径能探测；不存在的硬件能力不会成为可选项。

## 5. 输入、文件夹扫描与媒体探测

- [ ] 实现文件选择、多选和拖放。
- [ ] 实现文件夹导入对话框：目录、递归、全部/关键字/通配符/正则模式及表达式校验。
- [x] 实现不区分大小写的文件名过滤、`*`/`?` 通配符和带超时的正则匹配。
- [x] 实现异步、有限并发的文件夹枚举、去重和探测。
- [x] 调用 FFprobe JSON 并映射容器及多种流信息。
- [ ] 在转换页显示时长、分辨率、编码、帧率、码率、音轨和字幕轨。
- [ ] 为损坏文件、不支持文件、权限错误和扫描取消提供队列状态与提示。
- [ ] 加入媒体样本集成测试，包括 Unicode 路径和未知时长输入。

完成条件：批量添加期间 UI 保持响应；单个坏文件不影响其他文件完成探测。

## 6. 参数模型、兼容规则与命名

- [ ] 定义容器、流、编码器、质量模式、滤镜、字幕和时间范围模型。
- [ ] 实现能力驱动的格式/编码器选项。
- [ ] 实现中央参数验证器及字段级错误/警告。
- [ ] 实现质量与码率互斥、两遍编码约束、流复制约束、无损音频约束。
- [ ] 实现裁剪、缩放、旋转、补边后的尺寸计算与校验。
- [x] 实现包含日期、分辨率和音视频编码器 token 的输出命名模板解析、稳定展开语义、预览、校验和路径字符处理。
- [x] 实现覆盖、跳过、自动重命名策略及竞态复检。
- [ ] 为上述纯逻辑建立参数化单元测试。

完成条件：UI 无法提交已知无效组合；同一输入和配置生成确定的输出路径与参数快照。

## 7. FFmpeg 命令生成

- [ ] 实现视频转视频命令：软件编码与可用硬件编码。
- [ ] 实现视频转音频和音频转音频命令。
- [ ] 实现 CRF/CQ、目标码率和兼容的两遍编码命令。
- [ ] 实现时间裁剪以及裁剪、缩放、旋转、补边滤镜链。
- [ ] 实现音频提取。
- [ ] 实现外部 SRT 单轨字幕烧录。
- [ ] 实现作者、标题、专辑名和兼容封面的尽力保留；其他流默认不映射。
- [ ] 生成执行用参数列表、展示用命令文本和任务 manifest。
- [ ] 使用样本矩阵验证输出可被 FFprobe 重新读取且核心属性符合预期。

完成条件：MVP 支持矩阵中的每类转换至少有一个成功集成测试；执行从不依赖展示文本或 shell 拼接。

## 8. 队列与任务执行

- [ ] 实现队列状态机、合法转换守卫和只读状态通知。
- [ ] 实现添加、移除、重排、清空、重试与参数快照。
- [ ] 实现有界并发调度及运行中修改并行数的确定行为。
- [x] 实现队列防抖持久化、启动恢复和 `Running → Interrupted` 恢复映射。
- [ ] 实现恢复后不自动运行，以及用户重新开始时从头转换。
- [ ] 实现关闭主窗口隐藏到托盘，托盘菜单可打开主窗口或退出应用。
- [ ] 实现单实例激活，避免多个进程同时写入配置和队列。
- [ ] 实现退出时停止调度、保存队列、终止全部进程树并删除临时输出。
- [ ] 按任务 manifest 安全清理异常退出遗留的已知临时文件。
- [ ] 实现临时输出、成功提交、冲突复检和失败清理。
- [ ] 测试 FFmpeg 崩溃、磁盘写满、输出被占用、强制退出后的恢复和正常退出路径。

完成条件：退出后没有失管的 FFmpeg 进程或临时文件；重启后任务配置可恢复且不会自动运行。

## 9. 进度、日志与错误体验

- [ ] 显示每文件进度、总进度、速度、已用时间和可用时的预计时间。
- [ ] 对未知时长、停滞、两遍编码和进度回退定义显示行为。
- [ ] 批量节流 UI 进度与日志更新，避免日志洪泛阻塞界面。
- [ ] 实现任务日志详情、命令复制、原始输出查看和日志文件定位。
- [ ] 建立稳定错误码到中英文用户消息、技术详情和建议动作的映射。
- [ ] 实现可审阅的诊断信息复制或导出。

完成条件：长日志和多任务并行时 UI 仍可操作；常见失败无需阅读原始 FFmpeg 文本即可知道下一步。

## 10. UI 流程与易用性收尾

- [ ] 完成转换页双栏/单栏布局与页面级 `CommandBar`。
- [ ] 实现队列项状态、进度、主要操作和详情面板。
- [ ] 对破坏性操作、覆盖和带任务退出使用一致的确认体验。
- [ ] 为首次缺少 FFmpeg、硬件回退和无效参数提供 `InfoBar` 或对话框引导。
- [x] 在 `config` 不可写的临时会话中，在主界面持续显示醒目 `InfoBar`。
- [ ] 检查长文本、本地化扩展、文本缩放、键盘、读屏和高对比度。
- [ ] 检查转换运行期间的窗口缩放、导航、列表滚动和批量选择响应性。

完成条件：用户可在不打开日志的情况下完成正常转换；中英文和所有支持主题下核心流程无阻塞问题。
